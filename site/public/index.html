Bug fixes that prove themselves.

ApolloOffice is a small office of AI workers on your own computer. Add a GitHub repository and it picks up bug reports, reproduces them, writes a fix with a regression test and opens a pull request once the proof holds.

DownloadRead the README

The office at work: every worker has its own desk.

How it works

  • A fixed pipeline: Scout, Guard, Vet, Hunter, Repro, Fixer, CI, Reviewer, Submit and Watcher.
  • ApolloOffice checks the proof itself: the new test fails without the fix, passes with it, and your test command stays green.
  • Every pull request waits for your approval, with the diff, the proof and an editable text.
  • Pick a provider per worker: Claude Code or Codex with your own login, the Claude, OpenAI or Gemini API, or a local model through Ollama.

Runs on your machine

One binary for Windows, macOS and Linux. It uses your own GitHub and AI accounts and runs repository code in Docker on your computer or on any machine you reach with ssh. There is no ApolloOffice server, no account with us and no telemetry.
